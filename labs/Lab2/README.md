## Варіант
`Ж = 16`

- `16 mod 3 = 1` → статичний масив `Shape*`.
- `N = Ж + 100 = 116` → місткість масиву: 116 об'єктів.
- `16 mod 4 = 0` → гумовий слід: суцільна чорна лінія.
- `16 mod 2 = 0` → прямокутник вводиться по двох протилежних кутах.
- `16 mod 5 = 1` → прямокутник: чорний контур + кольорове заповнення.
- `16 mod 6 = 4` → заповнення прямокутника помаранчеве `RGB(255,128,0)`.
- `16 mod 2 = 0` → еліпс вводиться від центра до одного з кутів охоплюючого прямокутника.
- `16 mod 5 = 1` → еліпс: чорний контур + біле заповнення.
- `16 mod 2 = 0` → поточний тип об'єкта позначається у меню через `WM_INITMENUPOPUP` / `OnInitMenuPopup`.

## Збірка
1. Відкрити `Lab2.sln` у Microsoft Visual Studio 2022.
2. Обрати `Debug | x64`.
3. Виконати **Build → Rebuild Solution**.
4. Переконатися, що збірка завершилася без помилок.
5. Запустити програму клавішею `F5`.

Компілятор використовує `/utf-8`.

## Як перевірити програму
1. `Об'єкти → Крапка` — клацнути у клієнтській області.
2. `Об'єкти → Лінія` — затиснути ліву кнопку, протягнути, відпустити.
3. `Об'єкти → Прямокутник` — задати два протилежні кути; готовий прямокутник має помаранчеве заповнення.
4. `Об'єкти → Еліпс` — перша точка є центром; протягнути до одного з кутів охоплюючого прямокутника; готовий еліпс має біле заповнення.
5. Відкрити меню `Об'єкти` і перевірити позначку біля активного режиму.
