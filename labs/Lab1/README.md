## Варіант

Для лабораторної роботи №1:

- `В1 = Ж mod 4`
- `В2 = (Ж + 1) mod 4`
- `Ж = 16`

Отже:

- `В1 = 16 mod 4 = 0`
- `В2 = 17 mod 4 = 1`

## Збірка і запуск

Проєкт призначений для **Windows** та використовує `windows.h`, тому його потрібно компілювати за допомогою MSVC та Windows SDK.

У Microsoft Visual Studio:

1. Відкрити проєкт.
2. Обрати конфігурацію `Debug` та платформу `x64`.
3. Виконати **Build → Build Solution** або натиснути `Ctrl + Shift + B`.
4. Для запуску натиснути `F5`.

У параметрах компілятора використовується:

```text
/utf-8
```

## Примітка щодо GitHub Codespaces

GitHub Codespaces за замовчуванням працює у Linux-середовищі. Через це IntelliSense може показувати помилки для:

```cpp
#include <windows.h>
```

Це не означає, що Win32-проєкт має помилки. Збірка та демонстрація програми виконуються у Microsoft Visual Studio на Windows з установленим Windows SDK.
